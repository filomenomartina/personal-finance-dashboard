Release notes
Version history — click to expand
VersionDateChanges
v1.1Jul 2026Single common version for private and public use. Every owner-specific value moved out of the code and into the workbook’s Config sheet: currency symbol, locale, owner name, category order, wealth groups, card-repayment accounts, history window and the alert thresholds. Removed the dead alpha-era UI that no longer had anything to draw into. Reconciled three contradictory budget-pace thresholds into one configurable pair. The liabilities chart now splits out whichever debt dominates instead of matching on the word “mortgage”. Same file ships here and in the public repo.
v1.0Jul 2026Decision-first redesign wired directly to the workbook. Overview: on-track verdict, safe-to-spend, hero deltas, auto-insights, net-liquidity goal, 12-month cash-flow forecast, consolidated category trend, wealth donut, click-to-drill budget. Analyst: month-end cash, savings rate, net savings, expenses-by-subcategory (bars + 12-mo diamonds + trend arrows), per-category small multiples, and a collapsible balance sheet / bills / affordability panel. Categories and wealth groups driven by a Config sheet (auto-derived when absent). Continuous monthly + quarterly axes, privacy mode, and help badges throughout.
Alphas2026Earlier single-scroll dashboard iterations (net-worth & spending tabs, 30+ charts) — archived.
